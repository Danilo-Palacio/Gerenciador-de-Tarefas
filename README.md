# Gerenciador de Tarefas em Python

Projeto desenvolvido com Python e Tkinter com o objetivo de praticar conceitos de programação, organização de código, manipulação de dados, interface gráfica e persistência de informações em arquivos JSON.

## Funcionalidades

* Adicionar tarefas
* Alterar tarefas existentes
* Remover tarefas
* Marcar tarefas como concluídas
* Filtrar por status (Todas, Pendentes e Concluídas)
* Pesquisa por texto
* Ordenação por prioridade
* Ordenação alfabética
* Ordenação por status de conclusão
* Persistência dos dados em arquivo JSON

## Tecnologias Utilizadas

* Python
* Tkinter
* JSON
* Git
* GitHub

## Objetivos do Projeto

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em desenvolvimento de software, com foco na construção de aplicações reais, organização de código e boas práticas de programação.

Durante o desenvolvimento, procurei estruturar o projeto em módulos separados para interface e regras de negócio, simulando uma organização próxima à utilizada em aplicações profissionais.

## Processo de Desenvolvimento

O código foi escrito e implementado por mim.

Ferramentas de Inteligência Artificial foram utilizadas como apoio ao aprendizado, revisão de conceitos, esclarecimento de dúvidas e definição de tarefas de desenvolvimento, atuando de forma semelhante ao suporte de um mentor técnico ou Product Manager.

A implementação das funcionalidades, decisões de arquitetura, correções de bugs e refatorações foram realizadas manualmente durante o processo de desenvolvimento, com foco no entendimento da lógica e na evolução das habilidades de programação.
